# Transfert

Copiez ou déplacez vos workspaces Git entre deux hôtes Paseo.

- Choisissez un hôte et un nouveau dossier.
- Vérifiez les fichiers et les exclusions avant la copie.
- Retrouvez l’historique Git et les modifications locales dans un nouveau worktree.
- Confirmez l’archivage de la source après une copie vérifiée.

Installez le plugin sur les deux hôtes. Paseo 0.13.x, Node.js 22 et Git sont nécessaires. Les conversations et les fichiers ignorés par Git sont exclus. Les copies restent indépendantes.
